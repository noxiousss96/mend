mend applies an edit that an AI model wrote to a tree of text files, in four formats: a unified diff, SEARCH/REPLACE blocks, the V4A patch format, and text-editor tool calls as JSON. Every file is changed or nothing is. See SPEC.md for the full specification.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```

Node 22 or later, standard library only. `node check.ts <practice.json>` runs the public practice checks.
